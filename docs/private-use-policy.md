# Politica de uso privado

OMP es software de uso privado para gestion interna congregacional. No se concede permiso para redistribuir, revender, publicar como servicio de terceros ni usar la marca OMP fuera del entorno autorizado por el propietario del proyecto.

El acceso a datos administrativos de congregacion, plan contratado, consumo y metricas internas debe limitarse a ancianos autorizados y administracion tecnica del sistema.

Los datos de usuarios y congregaciones deben manejarse bajo principio de minimo acceso y solo para fines operativos internos.
