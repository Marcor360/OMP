# Revisión de calidad, seguridad y entrega de OMP 1.54.4

Esta versión parte de `release/1.54.3` y reúne las correcciones del calendario, la caché de Firestore y la revalidación web. Incluye Firebase JS 13.4.0, Stripe 23.1.0 y los flujos de revisión para Copilot, Codex y Cursor. Android usa el código local `15404` e iOS el número local `1.54.4`. El entorno de verificación fue `demo-omp`.

El [seguimiento del 19 de noviembre de 2026](seguimiento-node24-y-calidad-2026-11-19.md) recoge la migración a Node 24 y el avance de los pendientes de esta revisión. Las versiones y resultados de abajo corresponden a la entrega original de `1.54.4`.

## Por qué sigue apareciendo Node 22

| Contexto | Versión | Motivo |
|---|---|---|
| App, Expo, EAS y pruebas de reglas | Node 24.12 o posterior de la rama 24 | Firebase JS 13 y Rules Unit Testing 6 requieren esa línea. Este trabajo verificó Node 24.22.1. |
| Functions en Google Cloud y su suite | Node 22 | `functions/package.json` declara el runtime y CI lo reproduce. Stripe 23, Firebase Admin 14.5.1 y Expo Server SDK 8 funcionan en esa línea. Las herramientas de Functions requieren como mínimo 22.13. |
| Activación antigua de Codex Cloud | Node 22 al cargar `/workspace/.omp-setup/runtime.sh` | El script de la instancia antepone el binario de Node 22 en el PATH. Es adecuado para trabajar en Functions. En la raíz, comprueba `node -v` antes de instalar o validar y usa Node 24. |

`npm run quality:check` verifica ambas versiones. La app se ejecuta en Node 24 durante la validación y `OMP_FUNCTIONS_NODE` identifica el ejecutable separado para el backend. Una posible migración futura del runtime desplegado de Functions es un cambio de infraestructura que requiere probar la ejecución en staging.
